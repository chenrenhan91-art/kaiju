# KAIJU

English storefront for **KAIJU TRADE LIMITED**: wooden jewelry boxes, vanity storage, mirrors, and combs.

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Live site: [https://kaijuonline.com](https://kaijuonline.com)

Checkout is a request form. Orders are confirmed by phone at **+852 96915375**. First-order code: `WELCOME10`.
